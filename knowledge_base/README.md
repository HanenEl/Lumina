# Lumina Knowledge Base

This directory contains the structured skincare knowledge base that powers **Lumina**, providing the ingredient information and compatibility rules used to generate personalized skincare recommendations.

## Directory Structure

```text
knowledge_base/
├── ingredients.json
├── ingredient_warnings.json
└── skin_types.json
```

## Contents

- **ingredients.json** — Contains ingredient properties, functions, skin compatibility, irritation levels, comedogenic ratings, pregnancy safety, and additional metadata.
- **ingredient_warnings.json** — Defines ingredient interactions, contraindications, severity levels, and safety notes.
- **skin_types.json** — Contains skin type definitions and characteristics used to build personalized user profiles.

## Purpose

This knowledge base enables Lumina to:

- Match extracted ingredients with structured ingredient data.
- Evaluate ingredient compatibility with different skin profiles.
- Detect potential risks and contraindications.
- Support AI-powered personalized skincare recommendations.
